# Security

If you find a security problem in this repository or on the PaktLabs sites, please report it privately instead of opening a public issue. Use the Report a vulnerability button on the Security tab of this repository, or write to info@paktlabs.com. Reports are answered within a few days.

The live sites are paktlabs.com, data.paktlabs.com, web.paktlabs.com and automation.paktlabs.com. The only backend is the contact service under `services/contact-api`. Please do not run automated scans against the contact form, every accepted message sends a real email.

---

Bu repoda ya da PaktLabs sitelerinde bir güvenlik sorunu bulursanız lütfen herkese açık bir issue açmak yerine özel olarak bildirin. Bunun için reponun Security sekmesindeki Report a vulnerability düğmesi kullanılır ya da info@paktlabs.com adresine yazılır. Bildirimler birkaç gün içinde cevaplanır.

Canlı siteler paktlabs.com, data.paktlabs.com, web.paktlabs.com ve automation.paktlabs.com'dur. Tek backend `services/contact-api` altındaki iletişim servisidir. İletişim formuna otomatik tarama yapılmaması rica edilir, kabul edilen her mesaj gerçek bir e-posta gönderir.
